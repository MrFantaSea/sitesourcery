Public pages and the free preview

The ordinary pages use no inquiry form, visitor upload, advertising tracker, or page-level analytics code. The free preview stays in the editor tab.

Read public-page and preview details

Building, revising, and testing the private preview is free. The business facts and unsaved versions stay in the current editor tab and are not sent to Site Sourcery merely because a preview is made. Refreshing or closing the tab clears that unsaved work. Telephone and email links hand control to the application chosen on the visitor’s device. Infrastructure can still process the ordinary request records described below.

Accounts and access

An account is required only when you choose to save the preview as an editor project or use an unlocked Download.

Read account details

Account records can include the person’s name, organization, email address, protected credential digest, activation and recovery-token digests and expiries, session identifiers, accepted document versions, account state, and security timestamps. Site Sourcery does not store the readable password. Activation and recovery messages are sent through the transactional-message service used for the account.

Saved editor projects and versions

Saving creates a server-side editor project with the facts and versions needed to keep and Download that page.

Read saved-project details

A saved editor project can include its project and organization identifiers, name, customer-supplied business facts, selected look, generated HTML, version and content digests, accepted version, Download entitlement and transaction status, security checks, and lifecycle timestamps. The guest preview is not saved until the signed-in customer chooses a project and accepts the project terms.

Project records are processed by the Site Sourcery application, database, file-delivery, backup, and security systems used to provide and protect the service. Providers receive only the records needed for their assigned role under their applicable agreements.

Private preview and HTML Download

The accepted saved-version Download produces an HTML file. It does not publish or host the page.

Read Preview and Download details

The service records which saved version the customer accepted for Download. Preparing and delivering the file can use a short-lived download token, filename, content digest, status, request identifier, and timestamps. The browser places the resulting HTML file under the controls of the customer’s browser, operating system, and device.

Site Sourcery does not receive later edits made only to that downloaded file. If the customer self-hosts the file or gives it to another provider, that provider’s own terms, privacy notice, network records, and security practices apply. The $5 Download does not include Site Sourcery hosting, a domain, DNS changes, or publication.

Hive conversation guide

Hive is a short phone or in-person conversation with Zack. It does not place an order or start work.

Read Hive details

Calling Zack or meeting in person creates a direct communication. Reasonable notes can be kept as needed to understand the task and respond, but the conversation itself does not send a message to a customer, make a booking, request a review, change an invoice, connect a provider, order work, or save anything to an Abracadabra account. If work could be useful, its scope and price are stated separately in writing before the customer decides.

Application, database, backup, transactional-email, payment, file-delivery, and network providers can process the records needed for their assigned role. Technical records can include IP address, requested host and path, timestamp, response status, user-agent information, request identifier, rate-limit state, and security events. Site Sourcery does not sell customer information or use saved project content for behavioral advertising.

Domains, hosting, and publishing

The $5 Download includes no domain, hosting, DNS change, or Site Sourcery publication service.

Read domain and publishing details

A customer may self-host the downloaded HTML or contact Zack about a separately scoped domain or publishing service. An inquiry can create a direct communication. Provider, registrar, registrant, DNS, hosting, price, and publication records arise only if the customer later accepts a separate written scope and the applicable provider terms. A customer-owned domain remains the customer’s; Site Sourcery does not claim ownership merely because the customer asks for help.

The one-time $5 Download payment

The account shows an exact $5 one-time quote before payment. It is not a subscription or a charge for each version.

Read payment details

Secure card entry belongs to the payment processor identified at checkout. Site Sourcery can receive and store the editor-project identifier, accepted version, quote and checkout identifiers, $5 amount and currency, customer and transaction references, status, accepted document versions, and timestamps. Site Sourcery does not ask for or store the full card number or security code.

A completed $5 payment unlocks Download for that editor project. Later accepted versions and repeat downloads from the same retained editor project do not require another Site Sourcery purchase. A different editor project has its own $5 Download unlock. A held, expired, declined, cancelled, or otherwise uncompleted checkout creates no Download entitlement.

Retention, access, and deletion

Saved account and project records remain only as needed for the service, security, legal duties, and the controls actually offered.

Read retention details

Repeat Download without another purchase depends on the same saved editor project and its entitlement remaining available in the account. Site Sourcery makes no separate promise on this page that a saved project will remain available for a fixed period. Customers should keep their own copy of every downloaded file.

A customer may contact Site Sourcery about access, correction, or deletion. Requests can require identity and account-authority verification. Project content can be removed when deletion is completed, while minimal transaction, accepted-document, fraud-prevention, security, legal, and text-free lifecycle records may remain where required. Backups age out under operational schedules rather than being rewritten instantly.
