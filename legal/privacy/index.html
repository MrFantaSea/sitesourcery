Guest work and retained editor projects

Guest work stays in the current tab. A signed-in choice saves the project facts and versions needed for Download.

Read full project details

Before a guest saves, the business facts, selected look, review confirmation, and made versions remain in the current editor tab and are not sent to Site Sourcery merely because a preview is made. Refreshing or closing the tab clears that unsaved work.

When a signed-in customer chooses to save, the retained editor project can include organization and project identifiers, its name, customer-supplied facts, selected look, generated HTML, version and content digests, accepted version, Download entitlement and transaction status, security checks, and lifecycle timestamps. Those records are used to keep and deliver the project’s Download; they exist without an Alakazam subscription.

Private preview and HTML Download

The guest preview stays in its tab. Download delivers accepted project HTML but does not publish or host it.

Read full release-view details

Make my preview creates temporary HTML from the facts confirmed in the current tab. Opening a guest preview creates no Internet address, hosting, publication, rollback, suspension, or access-control state. For a retained project, the service records the accepted version and can use a short-lived token, filename, content digest, status, request identifier, and timestamps to prepare and deliver its HTML file. The browser places that file under the customer’s browser, operating-system, and device controls.

Download does not publish or host the page. Site Sourcery does not receive later edits made only to the downloaded file. If the customer self-hosts it, the chosen provider’s terms, privacy notice, network records, and security practices apply. Alakazam publication remains held and is not authorized by this notice.

Domains and outside providers

Domain preflight sends the candidate names to Cloudflare DNS for lookup only. It makes no reservation, registrar check, or quote.

Read full domain details

When you press the Domains page’s check button, the browser cleans the typed candidate and sends its .com, .net, and .org names in DNS queries to Cloudflare’s public DNS resolver. Cloudflare also receives ordinary request and network metadata, such as the IP address, request URL, time, and user-agent information, under its own terms and privacy practices.

The lookup checks public DNS only. It does not contact a registrar, reserve a name, prove availability, create a quote, authorize a purchase, or place an order. Any later domain registration, connection, renewal, transfer, or DNS work requires a separate written scope, customer approval, provider terms, and the provider data needed for that work. A customer-owned domain remains the customer’s.
